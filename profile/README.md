# Inola

Inola builds and serves specialized AI models for high-volume business tasks.
One API, pay per token.

## Models

| Model | What it is for |
|---|---|
| **Inola Decider** | decisions on documents |
| **Inola Injection Detector** | checks untrusted content for instructions aimed at your AI before it reads it |

Docs, pricing and a free plan: [inola.ai](https://inola.ai)

## Get started

1. Create an account at [inola.ai](https://inola.ai). New accounts get free credit.
2. Get an API key.
3. Send your first request (see the docs).
